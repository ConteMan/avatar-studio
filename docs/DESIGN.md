## 本轮状态合同

切片 3 在 Engine 外增加 `AvatarState` 状态层，保留 Engine 接口、绘图公式、默认状态和 11 层顺序。UI 的 `seed` 用于抽签，新增字符串 `drawingSeed` 保存发型轮廓细节输入。所有主图、候选缩略图、例图、SVG 和 PNG 导出都通过 `AvatarState.render`，仅在调用原 Engine 时把 `drawingSeed` 映射到引擎的 `seed`。旧配置缺少新字段时取其原 `seed`，保持原 SVG 逐字节一致。

整体随机与输入种子后提交遵守相同锁合同：保留已锁槽位选择；发型锁同时保留 `drawingSeed`；参数、颜色分别由自身锁控制，未锁参数和颜色仍可影响已锁部件。全部锁定后，抽签 seed 可以变化，SVG 必须逐字节不变。固定种子在相同初始状态与锁集合下得到相同结果；部分锁定时不承诺只凭抽签 seed 重建保留的输入。

手动点选和「换一个」始终可以修改已锁部件；「换一个」从当前值之外抽取，保证实际更换，保留绘图 seed。点选非空部件继续自动锁定该槽位。手动调色继续自动锁定配色；每次刷新按六个最终颜色重新匹配预设，自定义颜色不匹配时没有预设选中。

刷新统一同步主图、所有候选缩略图、部件/配色/裁切选中态及锁状态。滑块和颜色输入按动画帧合并刷新；状态值在输入事件立即更新，最后一次输入仍会刷新；保留输入节点和候选按钮节点，避免拖动或点击后丢焦点。分享与复制配置均包含 `drawingSeed`，新字段经过与 seed 相同的校验。分享和本地草稿使用同一格式版本封套。

`dots` 与 `cat` 的中文显示名在 UI 状态层按槽位覆盖，保持 Engine 的选项值与接口不变。说明文案采用实际层序，确定性保证限定于当前引擎及完整绘图配置。

## 当前职责

单 HTML 包含样式、Engine、AvatarState、Export、WorkLibrary 与 UI。Engine 无 DOM 依赖，已有 CommonJS 导出，`render(state, override)` 返回自包含 SVG。AvatarState 负责状态校验、随机锁合同、分享编码、旧草稿读写与绘图输入转换。Export 负责复制回退、PNG 失败提示和本次对象 URL 的释放，不参与绘图。WorkLibrary 负责 IndexedDB 本地作品库、旧草稿事务迁移、修订号冲突检测与快照存取。UI 持有当前编辑状态，负责控件、统一刷新、作品库对话框、预览另存、下载和分享。没有后端或外部运行时依赖；作品保存在当前浏览器 IndexedDB（`avatar-studio.library`），并保留旧 `localStorage` 草稿键以支持回退。

`render` 复制 `slots`，只在副本应用可选 `override.slot` / `override.value`，`override.viewBox` 可覆盖裁切。它读取参数与颜色，不应修改输入。锁定与配色预设索引是 UI 元数据，不参与绘图。Engine 自身不负责校验任意外部状态，URL 恢复由 UI 归一化后交给引擎。

## 当前复制与导出

预览旁的主按钮下载 PNG，旁边可复制分享链接。「更多操作」提供 SVG 下载和配置复制，支持用键盘展开、用 Escape 关闭并回到摘要按钮。

分享链接和配置 JSON 先走异步剪贴板。只有 `writeText` 成功后才提示已复制。接口不存在、同步抛错，或 Promise 被拒绝时，改用临时文本框调用 `document.execCommand('copy')`，并在结束时移除文本框、把焦点还给点击前的元素。只有返回值严格为 `true` 才提示成功；返回 `false` 或抛错时提示「复制失败，请手动复制」。拒绝尚未结束时不显示成功。

PNG 在点击时记下 `AvatarState.render` 的 SVG 和由当时 seed 得到的文件名。这次导出只用这份快照；之后的编辑和另一次点击使用各自的快照与对象 URL。绘制完成后释放这次的 SVG URL；下载触发后再过约 1 秒释放这次的 PNG URL。一次失败或释放不会撤销另一次仍在使用的 URL。

画布 2D context 不可用时提示无法创建画布。`drawImage` 抛错时提示无法绘制。`toBlob` 抛错时提示无法生成图片。回调没有 blob 时提示浏览器未返回图片。图片无法解码时提示无法解码。这些失败都建议改用 SVG。成功时提示已导出 1024×1024 PNG。SVG 下载和 JSON 复制读取同一次点击的统一状态。JSON 只含 `seed`、`drawingSeed`、`slots`、`params`、`colors`、`view`。

## 当前本地作品库与编辑历史

本地作品库由 `WorkLibrary` 模块维护，详细设计与两阶段安排见 [本地作品与编辑历史](local-work-history.md)。

- IndexedDB 数据库名 `avatar-studio.library`（版本 `1`），包含 `works`（主键 `id`，索引 `by_updatedAt`）与 `meta`（`migration.legacyDraft`、`activeWork`）两个对象仓库。记录使用独立存储版本 `STORAGE_VERSION = 1`，包含 `id`、`title`、`createdAt`、`updatedAt`、`rev`、`source`、`currentIndex` 和 `snapshots`。每条快照保存经 `AvatarState.persistableState()` 校验的完整配置（含 `drawingSeed` 与 `locks`）及简短操作名。每份作品最多保留 50 个可撤销步骤与当前步骤（51 份快照）；达到上限后继续编辑只丢弃最旧步骤。第一阶段的双快照记录保持可读，超限旧记录在加载时按当前位置裁剪并保留当前画面。
- 首次启动检测到合法 `localStorage` 键 `avatar-studio.draft` 时，在单一 `readwrite` 事务中同时写入「旧草稿」作品与 `migration.legacyDraft` 标记；事务失败时原子回滚并继续在内存中显示原草稿，重试只导入一次，成功后重复启动不再导入。旧 `avatar-studio.draft` 键保持只读不删改，以支持回退；后续编辑写入 IndexedDB 作品库。
- 每份作品独立保存完整步骤历史与 `currentIndex`。一次完整动作记一步；滑块、颜色选择等连续输入按控件合并，与当前步骤等值的提交跳过，回到紧邻上一步时收束，撤销后继续编辑会替换重做分支。编辑区工具栏提供「撤销」「重做」与步骤标记，`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z` 与 `Ctrl+Y` 在非文本输入焦点生效；按钮标题与 `aria-label` 显示下一步操作名或禁用原因，冲突时暂停历史操作。
- 打开首页恢复上次活跃作品及其步骤位置；空库仅在首次有效编辑时建立记录。点击页头「我的作品」打开原生 `<dialog>` 列表，按最近编辑倒序显示实时配置渲染的缩略图、标题和更新时间，支持打开恢复与行内重命名，并说明数据仅存于当前浏览器与站点。窄屏保持 `144×144px` 粘性预览与编辑空间，作品列表独立打开。
- 打开有效分享或点击示例先进入预览态，不写入作品库也不修改原作品；查看、下载和返回原作品均保持原作品不变。点击「保存为新作品」或首次有效编辑时以预览原稿作为第零步新建独立作品，仅在 IndexedDB 提交成功后才通过 `history.replaceState` 移除 URL 中的分享参数 `s`。打开无效或不兼容分享时，提示失败并保留原有本地作品（空库时回退默认形象）。
- 单标签内通过串行写队列合并连续编辑并跳过重复快照；编辑与连续输入同步写入按标签归属（`sessionStorage['avatar-studio.tab-id']`）隔离的待保存暂存键 `avatar-studio.pending-edit`（不改动旧键 `avatar-studio.draft`，不使用阻塞式 `beforeunload`），新建作品复用确定性 `workId` 防止回放重复建档。暂存只在对应历史实际落盘、用户明确选择重新载入新版放弃本页分支、或副本已确认落盘后清理；冲突、写入失败和启动回放失败保留本标签完整历史与当前位置，连续刷新后仍可重试或保存副本。清理按「读到的暂存仍是当前暂存」比较，旧事务完成或异步回调不能删除更新的暂存。在 `pagehide`、`visibilitychange` 隐藏及切换作品前冲刷待发编辑（不把 `pagehide` 异步写当作持久化保证）。完整历史只由写入它的 `tabId` 回放；刷新与前进后退沿用归属，新标签、`window.open` 与复制标签重新分配归属，旧格式暂存仍按最终状态兼容回放。若 IDB 已落盘同一历史/同 `workId` 则幂等清理；若 `rev` 已被其他标签推进且内容不同则拒绝自动覆盖并展示刷新后仍可处理的冲突恢复栏。浏览器进程被强杀前尚未写入或 `localStorage` 不可用/满额时无法依赖暂存恢复，仍可通过配置 JSON 导出备份。跨标签写入与重命名在单事务内校验 `id` 与 `rev`，发现修订号不一致时拒绝覆盖，保持当前编辑画面并提供「重新载入新版」「保存为副本」与「导出配置 JSON」。配额不足或存储不可用时明确提示「更改尚未保存」，保留编辑画面、本页完整分支和上次成功保存的版本，并提供重试保存与配置 JSON 导出；暂存本身也无法写入时明确提示刷新会丢失当前分支；冲突副本使用确定 `workId`，连点或并发只建立一份；有效分享预览中若旧草稿迁移失败，则在预览栏持续提示并提供独立的「重试迁移旧草稿」与「返回原草稿」入口，不误标为分享保存失败。

## 当前分享与恢复格式

格式版本是整数 `1`。分享和草稿使用同一个封套：

```json
{ "v": 1, "state": { "seed": "", "drawingSeed": "", "slots": {}, "params": {}, "colors": {}, "view": "half", "locks": {} } }
```

`state` 是归一化后的绘图与锁定状态，不含由颜色重新匹配的 `palette`。分享把封套按 UTF-8 JSON → base64 → 将 `+`、`/` 替换为 `-`、`_` 并去掉尾部 `=` → `encodeURIComponent`，放在首个查询参数 `s`。草稿把同一封套以 JSON 文本存在 `localStorage` 键 `avatar-studio.draft`，不放进地址栏。点击分享才把当前配置写入 URL 并尝试复制链接，并沿用当时的 `history.state`。新的 `s` 放在查询串里，hash 留在查询串之后；路径和其他查询参数保留，原有的一个或多个 `s` 不重复留下。只含 hash、hash 中含有 `?`，或参数名被编码成 `s` 时，也按这个顺序组装。编辑不会重新编码一条新分享。

初始化来源写在根元素 `data-avatar-source`：`share` 是版本 1 分享，`legacy-share` 是没有 `v` 的旧分享，`draft` 是合法本地草稿，`default` 是默认形象。优先级是合法分享、然后合法草稿、最后默认。存在 `s` 时，即使值为空、过长、无法解码、结构不合法或版本不是 `1`，也使用默认形象并提示，不读取、不写入、不清除草稿。没有 `s` 时才读草稿。

有限数字且不等于 `1` 的 `v` 视为无法识别的未来版本，明确提示，不按旧结构猜测。`v` 不是该数字时视为非法。没有 `v` 的对象仍按旧分享解析：顶层就是状态，而不是封套。这样现有无版本链接保持同一 SVG。不保证将来的绘图引擎仍能还原今天的链接。

空值、编码值超过 8000 字符、URI / base64 / UTF-8 / JSON 解码失败，或状态对象结构不合法时，回默认并提示链接无效。顶层及可选的 `slots`、`params`、`colors`、`locks` 必须是非数组对象；空对象可以补齐默认值。未知字段忽略。读取兼容标准 base64 的字符与补齐 padding。

- `seed` 去 C0 控制字符并 trim，截取前 160 个 JavaScript 字符串码元；空值保留默认。`drawingSeed` 应用相同规则，缺失或无效时取归一化后的 `seed`。
- `slots` 仅接受对应白名单，缺失或不合法字段用默认。
- `params` 仅接受有限数字，按范围限幅并取两位小数。
- `colors` 仅接受六位十六进制颜色，转小写；缺失 / 非法值用默认。
- `view` 仅接受三个已知值。锁仅接受严格 `true`，其余不保留；`palette` 根据最终颜色重新计算，不信任传入索引。

复制 JSON 按钮仅导出 `seed`、`drawingSeed`、`slots`、`params`、`colors`、`view`，不包含锁等 UI 元数据，与分享载荷并不相同；当前没有 JSON 导入入口。

合法或非法分享首次打开只改变当前页面，不读取、不写入、不清除草稿，地址栏里的 `s` 也保留。随机、点选、换一个、锁定、参数、颜色、裁切和例图点击都是编辑，会立刻把归一化后的最终状态写入草稿；同一次编辑只写一次。初始化、刷新画面、复制分享链接、复制配置和下载不写入，也不移除 `s`。保存是同步的，不使用 `beforeunload`。

草稿成功写入后，若地址栏还有一个或多个 `s`，页面用 `history.replaceState` 去掉这些参数，并保留路径、其他查询参数、hash 和现有 `history.state`。之后直接刷新不再优先旧分享，而是恢复刚保存的草稿。保存失败时不移除 `s`，刷新仍按分享优先，不会改读另一份旧草稿，也不显示已保存。`replaceState` 缺失或抛错时，编辑、渲染和导出继续；提示说明草稿已保存但刷新仍会打开旧链接，同一种提示只出现一次。

`localStorage` 读或写抛出、数据损坏或空间不足时，页面仍使用内存中的状态编辑、分享和下载。损坏或未来版本的草稿退回默认并说明原因，不把另一份分享静默换成草稿。同一种保存失败只提示一次，成功后再失败可以再提示；提示写明不可用或空间不足，不显示已保存。

## 当前随机与已知限制

随机按钮生成新 seed；手动输入后按回车或离开输入框提交，也调用同一 `randomize`。未锁槽位由 `fromSeed` 抽签；发型未锁时同时更新 `drawingSeed`，锁定时保留。参数锁和颜色锁分别控制随机化。全部锁定时 seed 仍会变化，SVG 逐字节不变。手动操作可改变锁定部件；锁的作用域是整体随机流程。

整体随机、输入种子和例图把引擎原本抽到的 `rays` 映射成 `plain`，其余抽签结果沿用原规则。「换一个」从可选背景中抽取，排除当前值。旧草稿和分享仍按原样绘制放射背景，并提示可以更换。背景已锁定时，整体随机保留原背景。

手动编辑后的主图、缩略图和选中态统一刷新。复制和 PNG 的失败提示按上一节处理；系统剪贴板是否真正写入、真实读屏器、Safari、微信内置浏览器和真机仍需单独验证。历史复现与浏览器证据见 [实现评估](implementation-review-2026-11-26.md)，其中锁定、同步、分享、导出及手机编辑与基础可访问性已随对应切片落地，其余未测项目不计作已完成。

## 当前响应式布局与可访问性

桌面宽屏（`> 1080px`）保持左预览、右编辑面板的双栏布局，左侧预览列在页头下方粘性定位。中等宽度（`721px–1080px`）转为单栏。窄屏（`<= 720px`）在页头下方保留 `144×144px` 粘性预览，下载、分享与更多操作排在右侧。`ResizeObserver`（回退为 `resize`）同步页头和预览区高度，根容器用 `scroll-padding-top` 为聚焦和定位目标留出滚动空间。窄屏主要交互控件触控高度为 40–44px，并适配安全区与 `prefers-reduced-motion`。

编辑区提供一行从随机生成到下载的指引，例图与种子输入各自折叠。页头的「关于」打开原生对话框，可用关闭按钮或 Escape 回到编辑器；弹窗标题下方显示当前应用版本状态：优先读取内联版本元数据（`<meta name="app-version">` 或 `html[data-app-version]`，自建构建 `build:selfhost` 自动从 `package.json` 校验并注入唯一 `<meta name="app-version">`，由 `verify:selfhost` 校验一致性且不增加 `build-meta.json`，同时兼容 `file://` 直接打开），否则在 `http:`/`https:` 环境下通过相对路径读取同源 `build-meta.json` 的 `packageVersion`（兼容 `version`）并显示「版本 `<semver>`」；直接打开根目录源码（`file://`）或元数据缺失/异常时安静回退显示「源码预览」。官方构建与校验以 `package.json` 的 `version` 为唯一权威来源并校验 `build-meta.json` 一致性，同时保持根目录 `index.html` 与 `dist/index.html` 逐字节一致。

基础可访问性覆盖：

- 预览画布提供 `role="img"` 与 `aria-label="当前半身像预览"`；页面标题层级按 `h1` → `h2` 组织。
- 连续参数滑块使用显式 `<label for>` 绑定可见名称，并通过 `aria-describedby` 关联数值文本、同步 `aria-valuetext`；键盘方向键调节时保留焦点，数值与图形同步更新。
- 编辑历史提供 `role="group"` 的撤销/重做按钮组，按钮在空历史或冲突时禁用并通过 `title` / `aria-label` 说明原因，撤销或重做后若按钮变为禁用则把焦点移到仍可用的相邻控件；文本输入内不劫持 `Ctrl/⌘+Z`。
- 裁切视图（`role="group"`）、部件选项、配色预设及全部锁定按钮暴露 `aria-pressed`；槽位锁定、连续参数锁定、配色锁定、槽位「换一个」和例图按钮提供上下文 `aria-label`；缩略图和色点装饰容器标记 `aria-hidden="true"`。
- 操作提示 `#toast` 使用 `role="status"`、`aria-live="polite"`、`aria-atomic="true"`；按钮、输入框与折叠摘要提供 `:focus-visible` 焦点轮廓。尚未进行真实读屏器测试。
