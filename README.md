# 半身像工坊

用种子拼出半身头像，调五官、发型和配色，再导出矢量图或 PNG。同一份配置始终得到同一张图。

这是独立项目。Idealand 只保留想法，不放这里的代码。

许可还没定。没有后端，不进 Dokploy。公开地址准备用 Cloudflare Pages 或 Workers，还没部署。

## 标志

母版是圆角六边形里挖空的半身印章，文件 `rounds/R05-2026-11-26/shu.svg`。印章按 0.66 缩放，视觉中心在六边形正中。墨色 `#1b1a18`，深色底用纸色 `#f6f5f1` 填同一条路径。字标是「半身像工坊」，不是曲线。这版还没放进页头。几何记录在 `rounds/FINAL-2026-11-26.md`。
