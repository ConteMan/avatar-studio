# 半身像工坊

用种子拼出半身头像，调五官、发型和配色，再导出矢量图或 PNG。当前引擎下，相同完整绘图配置得到同一张图。

代码与项目文档在本独立仓库维护。

产品方向已确定为轻量头像工坊。没有后端，不进 Dokploy。初版采用 Cloudflare Workers Static Assets 托管，还没部署。许可还没定。

## 本地使用与自检

用浏览器打开根目录的 `index.html` 即可使用，无需构建或安装运行时依赖。跨浏览器、真机及剪贴板权限的验证边界见实现评估。

维护自检需要 Node.js 26 和 POSIX shell，不需要 `npm install`。在仓库根目录运行：

```sh
./scripts/selftest.sh
git diff --check
```

从其他目录调用时使用脚本的实际路径；脚本会自行定位仓库。成功时 Node 测试汇总的失败数为 0，任一断言失败时非零退出。自检覆盖固定 SVG 摘要、重复渲染、输入不可变、144 个部件与裁切用例、实际 11 层拼接顺序，以及随机锁定、手动换部件、新旧分享和非法输入回退；不替代浏览器视觉验收。参与开发前阅读 [贡献指南](CONTRIBUTING.md)。

## 随机与锁定

「随机生成」重抽未锁的部件、参数和配色。输入种子后按回车或离开输入框也遵守同一规则。部件锁保留选择及其随机轮廓细节；参数锁和配色锁独立，未锁参数或颜色仍可影响已锁部件。全部锁定后，重复随机保持同一 SVG。手动点选和「换一个」仍可更换锁定部件。

发型细节单独保存在 `drawingSeed`；旧分享缺少此字段时沿用原 seed。要保留编辑和锁定后的外观，请复制完整分享链接或配置；仅凭抽签 seed 不保证重建已保留的输入。

刷新会恢复本机草稿。合法分享优先于草稿；空的或无法识别的分享回到默认形象，并说明原因，不会改读草稿。打开分享链接不会立刻覆盖已有草稿，开始编辑后才保存。草稿保存成功后，地址栏里的旧分享参数会被去掉，直接刷新恢复刚才的编辑；保存失败时旧链接仍留着，刷新不会改读另一份旧草稿。编辑不会自动生成新的分享链接。再次复制分享时，新的参数仍在查询串中，页面锚点留在后面。新的分享和草稿使用格式版本 1，没有版本号的旧链接仍可打开。无法识别的更新版本会提示，不保证将来的绘图引擎仍能还原今天的链接。浏览器存储不可用、已满或草稿损坏时，仍可编辑、分享和下载。

## 标志

母版是圆角六边形里挖空的半身印章，文件 `rounds/R05-2026-11-26/shu.svg`。印章按 0.66 缩放，视觉中心在六边形正中。墨色 `#1b1a18`，深色底用纸色 `#f6f5f1` 填同一条路径。字标是活字「半身像工坊」，不是曲线。页头使用 32px 的派生文件 `assets/mark.svg`，路径与母版相同；母版本身不改。几何记录在 `rounds/FINAL-2026-11-26.md`。

`assets/favicon-32.png` 只作浏览器图标。需要重做时，在仓库根目录执行一次 `magick -background none assets/mark.svg -resize 32x32 assets/favicon-32.png`。页面不调用这个命令，也不为此安装依赖。
