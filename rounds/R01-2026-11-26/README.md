# R01 · 2026-11-26

半身像工坊的第一轮标志。这一轮不合并、不部署。

## 所有者的反馈

> 看了你的 Logo 设计截图，我只能说，离那种比较标准的设计还差得远，如果要使用非标准图形的线条，我觉得你的设计很难达到那种让人舒服的线条走向，我们可以先参考优秀案例来看下，比如 https://logoinspo.com/ ，https://logosystem.co/ 。先看下怎么先能达到标准，再考虑怎么能有创意、设计。

对照过这两个画廊里的几何标志和人物标志。它们的线条能说清几何：圆、直线、同一套圆角，曲线相切。人物被收成很少的几块形，不是手估出来的鼻子、胸口和发丝。下一轮先按这个标准画，创意等线条站得住再加。竞品图不放进这个公开仓库。

## 简报

- 产品名是半身像工坊。目录和仓库名是 avatar-studio，所有者已确认。
- 一句话：在浏览器里用一个种子拼出半身像，裁切、换色，整份配置留在链接里。
- 主场景是 Web 与 PWA：页头组合标、16/32 标签页图标、浅色和深色。不做 macOS 菜单栏，也不做应用商店图标。
- 颜色沿用页面：纸色 `#f6f5f1`，墨色 `#1b1a18`，朱砂 `#a9322b`。
- 不沿用页面里现成的那只角色。不画账号占位图标那种圆头加肩。

## 同类和撞脸

同类产品的标志通常是一张示例脸，或一块抽象几何。占位头像则几乎都是圆脑袋加两肩。这一轮避开这两类，改成一块能在 16px 靠剪影成立的半身。

已对照的自有标志：

- Ceave 衔草鸟是一只鸟，标签页图标是白鸟坐在 `#e23b2d` 的圆角红底上。这一轮没有鸟，也没有红底。朱砂和那只红接近，所以只做小面积点缀。
- Calmtile 是衬线字母 C 加一块绿色方砖（`#3d5045`）。这一轮没有字母，没有方砖，没有绿。

仓库是公开的，所以这里不放竞品截图。

## 这一轮做了什么

四个方向，都是粗剪影。可编辑源是同目录的 SVG，路径按身体、头发、后层分开。`logo.pen` 是 pen.dev 命令行写下的同一套几何，给以后手调用。这版命令行不接受 PingFang SC，画布上的标题因此写成 Inter 的 “R01”；四个方向的名字在画框上。字标仍是页面上的「半身像工坊」，还没有转成曲线。

| 方向 | 表达 | 和别人的差别 |
|---|---|---|
| A 平裁 | 平顶发线，胸口开槽，槽里一块朱砂 | 槽是裁切，不是账号图标。槽内色块在 16px 会糊，单色时只剩槽。 |
| B 叠影 | 同一半身向右上错开约 70×64 | 第二道边在 16px 大约还有 1px。层多了会像重影。 |
| C 侧影 | 朝右的侧面，鼻子在外轮廓上，发髻在后颈 | 不像正面的人头图标。胸口轮廓现在不平，鼻子也偏短。若被看成鸟喙，就和衔草鸟撞意。选它的话，下一轮先拉平胸口、加长额头。 |
| D 发束 | 左侧长发垂过胸切 | 剪影不对称，16px 仍能看出那缕头发。最不像账号图标。 |

## 推荐

先精修 D 发束。它在小尺寸靠头发的外轮廓就能认出来，朱砂用在头发上，不需要红底，也不是页面里那只角色。

C 是第二选择，如果更想要「一幅肖像」而不是「一个正面半身」。A 最直白地说了裁切，但最接近普通的人头图标。B 说了层，小尺寸容易糊成一个影子。

## 看过和没看过

看过：本目录 `index.html` 在无头 Chrome 里的整页，包括 180px 符号、16 格放大、32px、16px，以及 D 的浅色和深色页头。

没看过：真实浏览器标签页、安装到主屏之后的图标、把 SVG 丢进 pen.dev 桌面再导出的结果。命令行导出的 PNG 只用来确认画布写上了这些路径。

PWA 的 80% 安全区在汇总页里是示意。符号现在铺满 1024 画布，定稿时再缩进安全区。16px 没有另做一套简化稿；A 的槽内色块是最可能在 16px 消失的细节。
