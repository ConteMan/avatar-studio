# R03 · 2026-11-26

上一轮的线条方法留下。这一轮只改一处：左边肩角换成一块更大的圆，两边不再对称。未合并，未部署。

## 上一轮原话

> 我觉得在设计上已经向标准迈进很多了，线条很流畅，说明这个设计方法是成立的，但是这个设计有点像我们认知里的印章，我觉得要加一些变化避免和一般认知重合。

## 这一处改了什么

R02 的左右肩角都是半径 48，半身左右一样，整块又实，所以像一枚肖形印。

现在左肩圆与左下颌圆外切，并且切在左壁 x=220 上。右肩仍是半径 48。头、下颌和右边都没动。

| 零件 | 圆心 | 半径 |
|---|---|---|
| 头 | 512, 318 | 168 |
| 下颌过渡，左右各一 | 662.24, 456 和 361.76, 456 | 36 |
| 左肩 | 361.76, 633.76 | 141.76 |
| 右肩上角、下角，和左下角 | 756, 540；756, 736；268, 736 | 48 |

左肩半径是左下颌落点到左壁的距离：361.76 − 220。圆心在这条垂线上，所以它和左下颌圆、左壁、肩顶的延长线都相切。接触点是 (361.76, 492) 和 (220, 633.76)。

试过把另一团同半径的圆叠到头上。交角要么尖，要么鼓出多余的圆，所以没留。也试过只把头平移，小尺寸仍是同一块对称的印章。

## 还没做的

没有第二处变化，没有发束、槽和侧影。它仍是一个几何人像。16px 下半径 36 的过渡大约半像素，会并进剪影。左边这块大圆在小尺寸上是肩线一侧更斜。
