# R02 · 2026-11-26

按所有者对 R01 的反馈，先做一版几何标准稿，不加创意。未合并，未部署。

## 上一轮原话

> 离那种比较标准的设计还差得远。如果要使用非标准图形的线条，很难达到让人舒服的线条走向。先参考 logoinspo.com 和 logosystem.co。先达到标准，再考虑创意。

随后确认：按圆和直线来画，并标出圆心和半径。

## 这一轮的几何

一个半身，七个圆，外加直线。圆与直线、圆与圆都相切，没有手估的贝塞尔。

| 零件 | 圆心 | 半径 |
|---|---|---|
| 头 | 512, 318 | 168 |
| 下颌过渡，左右各一 | 662.24, 456 和 361.76, 456 | 36 |
| 肩块四角 | 756, 540；268, 540；756, 736；268, 736 | 48 |

肩块外沿 x=220 与 x=804，顶 y=492，底 y=784。下颌圆与头外切，并切在肩块的顶边上。四角是四分之一圆，切在肩块的直边上。

先画过一版把肩线放到很大的圆上、再切到水平底边。底边两端收成尖角，所以弃了。现在的肩是一块带圆角的矩形，头坐在上面。

## 还没做的

没有发束、叠层、槽和侧影。小尺寸只靠圆头加肩块。16px 下半径 36 的过渡大约半像素，会并进剪影。

它仍是一个几何人像，不是画廊里那种更收敛的符号。线条这版先站稳，创意等这版被接受再加一个。
