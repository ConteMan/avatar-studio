# 引擎与状态回归

统一入口为 `scripts/selftest.sh`，需要 Node.js 26、POSIX shell，无 npm 安装步骤。入口从自身路径定位仓库，交给 Node 原生测试运行器；任何加载或断言错误均非零退出。

## 来源与覆盖

`fixtures/svg-baseline.json` 于 2026-11-26 从保留的当前引擎一次生成并存储，来源为提交 `2178801` 中的 `index.html`，源码 SHA-256 为 `409acac39c73a415f755bce9a63dd4fbef2292edf07c4a6dc8c039dd520e4b2c`。保存 4 份完整固定状态及其 SVG 摘要，并保存默认状态下逐一替换 48 个部件选项、应用 3 种裁切的 144 份摘要。固定状态另覆盖中文 / emoji、参数上下界、自定义配色与不同发型。

测试读取这些已提交的预期摘要，与当前原引擎的输出比较。运行 selftest 不会写入或重新生成预期值，也不检查整个 HTML 的哈希，以便后续 UI 切片保持绘图基线同时修改页面。Logo 母版另有固定哈希断言。

`engine-loader.cjs` 只接受一个无属性内联脚本，在已有且唯一的 CommonJS 导出处截断，在 Node VM 中执行原 Engine。UI 不会执行，VM 不提供 DOM、require、process 或网络 API，并禁用动态代码生成、限制初始化时间。结构不符时直接失败并要求人工确认提取边界；VM 用于隔离受信任的仓库引擎，不作为运行不可信代码的安全沙箱。

`logo.test.cjs` 核对母版哈希、页头 `assets/mark.svg` 与母版同一条路径且不采用「满」、SVG 自包含，以及 32×32 PNG 图标的文件头尺寸。它不栅格化，也不把页头改动算进绘图摘要。

每次渲染都冻结嵌套输入、比对前后状态，并重复渲染核对逐字节一致。144 个用例检查固定摘要、裁切及 NaN / Infinity / undefined，还验证 `override` 与直接选择部件的结果等价。层序检查仅在测试 VM 中包裹原层函数，在实际返回片段前插入标记；分别断言调用顺序、最终 SVG 顺序，以及去掉标记后与未插桩渲染一致。生产源码不改。

## 修改基线与反证

摘要失败时先检查引擎输出与改动原因，不应通过重新生成摘要掩盖回归。绘图公式与层序按当前约定保留；如未来获准改图，应在独立 PR 解释每项输出差异、复核图像、更新完整固定状态及预期摘要，绑定新来源提交和源码哈希，由评审者确认。

验证测试能否抓住问题时，在仓库外创建自含副本，故意把一份预期摘要改为 64 个 `0`，再调用副本的 selftest，必须非零退出并指向摘要不一致。也可在副本交换 `neck` 和 `bodyBack` 的实际拼接次序，应同时触发摘要与层序失败。原仓库无需临时损坏文件。

## 状态合同

`state-loader.cjs` 在唯一 UI 入口前提取 Engine 与 AvatarState，在无 DOM 的 Node VM 中执行；仅补充 UTF-8 和 base64 编解码原语。`state.test.cjs` 验证旧配置的四个固定摘要和 144 个部件裁切摘要，以及全锁重复随机、发型绘图 seed 保留、参数与配色独立锁、锁定后的手动更换、固定种子确定性及输入不可变。

状态测试还覆盖含中文 / emoji 的新旧分享往返、新字段校验与非法输入回退、六个最终颜色的预设匹配，以及按槽位区分的同名标签。草稿测试覆盖分享优先、首次打开分享不读写存储、编辑后保存、旧分享与版本 1 的同一 SVG、未来版本、空参数，以及损坏、不可用和满额存储。另覆盖成功保存后去掉重复的旧分享参数、保存失败时保留分享，以及其他查询参数与 hash。显式分享覆盖纯 hash、无 hash、其他查询加 hash、重复或编码的 `s`，以及 hash 中含 `?` 时查询串仍在锚点之前。原引擎与黄金摘要不重新生成。

`export.test.cjs` 用注入的剪贴板、文本框和画布覆盖复制与 PNG。它检查异步写入成功、Promise 拒绝后再回退、同步抛错、回退返回 false、回退抛错、焦点归还和文本框移除；以及 context 为空、`drawImage` 抛错、`toBlob` 抛错、`toBlob` 得到 null、图片解码失败。成功的 PNG 用例核对 1024 绘制、点击时的 SVG 与文件名，以及两次导出各自释放自己的对象 URL。这些用例不操作操作系统剪贴板，也不解码真实 PNG。

`library.test.cjs` 使用支持真实事务回滚、配额错误与失败注入的 IndexedDB 替身，覆盖旧草稿事务迁移和重试、第一阶段作品记录、完整历史回放与撤销位置恢复、同值与相邻收束、撤销后分支替换、50 个可撤销步骤上限及加载裁剪、跨标签修订冲突、写入失败保留上次成功版本和未来版本跳过。它还覆盖完整历史与旧格式都只由确认归属的标签回放、无本 id 时不回退读取其他标签旧单条/byTab、未确认活跃文档归属时不自动提交、读暂存后写入新暂存的交错、失败/冲突回放保留暂存与修正后重试、比较后清理、写租约撤销后 readwrite 被阻止、确定性副本 `workId` 与连点/落盘后立即刷新、暂存写入失败返回 false。活跃文档锁、复制标签/强制 `back_forward`、锁不可用降级、无暂存换身份首改、真实 BFCache 身份修复、pagehide 定时/在途写取消、安全恢复栏与副本状态同步、歧义/离页重命名和作品切换门禁由实际浏览器检查；真实系统复制标签菜单、Safari/Firefox 等未覆盖。

`dist.test.cjs` 覆盖显式白名单打包的幂等性与旧残留清理、白名单外文件拦截、无敏感路径泄露、隔离候选夹具默认拒绝生产 `domains` 与非 `candidate` 状态、清单驱动门禁（`verify:ci`）对未知/缺失 `stage` 的拦截、显式 `release` 模式与 `verify:ci` 放行干净授权发布配置并拦截脏树/提交 SHA 不符/域名不匹配/伪造 `released: true`，以及本地 `dist/` 预览服务器的首页、查询分享、`/index.html` 307 重定向、静态资源 `Content-Type` 与缓存头、ETag/304、`/_headers` 隐藏和未知路径/缺失资产真实 404（不走 SPA 回退）。

## 未覆盖

144 个用例仅覆盖单选项与裁切，不是 653184 种组合的穷举、像素视觉回归或浏览器验收。Node 里的复制与 PNG 用例使用注入失败，不操作操作系统剪贴板，也不打开真实下载文件。自动测试不覆盖可访问性、真机、Safari、微信内置浏览器或远端发布；UI 改动应补实际浏览器检查。当前行为与后续目标见 [DESIGN.md](../docs/DESIGN.md)。
